🧭 Как работает маршрутизация
1. Перехват — весь трафик из LAN идёт в Sing-box (TProxy + REDIRECT).
2. DNS — домен резолвится через dns-router (AdGuard) или через VPN.
3. Правила по порядку — устройства → каталог → свои правила → свои .srs → финал.
4. Группа — если домен попал в список, трафик уходит в селектор группы (например proxy-youtube).
5. Failover — менеджер мониторит задержки и переключает селектор на живой сервер.

Основной DNS — роутера (AdGuard Home). Резервный — через VPN. Чтобы всё шло через роутер — оставь dns-router включённым, а dns-remote выключенным.
