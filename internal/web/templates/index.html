Серверы

Управление VPN-серверами

🧭 Как работает маршрутизация
1. Перехват — весь трафик из LAN идёт в Sing-box (TUN или mixed-inbound).
2. DNS — домен резолвится через dns-router (AdGuard) или через VPN.
3. Правила по порядку — устройства → каталог → свои правила → свои .srs → финал.
4. Группа — если домен попал в список, трафик уходит в селектор группы (например proxy-youtube).
5. Failover — менеджер мониторит задержки и переключает селектор на живой сервер.
Всё в реальном времени — правила загружены в память при старте, проверка за миллисекунды.

🌍 Свои .srs URL

Прямые ссылки на .srs файлы.
Для каждой группы отметь, какие серверы в ней участвуют, и задай порядок. Первый — самый приоритетный. Можно создавать ручные группы.
Для конкретного устройства (по IP) можно назначить: весь трафик через прокси, напрямую, или заблокировать. Правило устройства имеет приоритет над всеми списками.
Основной DNS — роутера (AdGuard Home). Резервный — через VPN. Чтобы всё шло через роутер — оставь dns-router включённым, а dns-remote выключенным.
